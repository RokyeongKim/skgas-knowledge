## 사업 개요

**구역전기란?**
정부 허가를 받아 특정 구역 내에서 SK가스가 **전기를 직접 생산·판매**하는 사업. 현재 UGPS는 SMP 기준으로 한전에 팔지만, 구역전기 사업자가 되면 **데이터센터·공장에 장기 PPA로 직접 판매** 가능 → 마진 대폭 개선.

**왜 하나?**
① LNG #5 탱크 물량(발전용) 확보  
② 전기·스팀 동시 판매로 이중 수익  
③ 울산 석화단지·AI DC 고객을 SK가스 생태계에 Lock-in

## 집단에너지 vs 구역전기

| 구분 | 집단에너지 | 구역전기 |
|------|-----------|---------|
| 개념 | 한 발전소에서 전기+스팀 동시 생산 → 공급 | 정부 허가 구역 내 전기 직접 판매 |
| 인허가 | 집단에너지법 적용, 인허가 복잡 | 구역전기사업자 허가 취득 필요 |
| 수익 구조 | 전기 + 스팀 이중 수익 | 전기 단독 (PPA 기반) |
