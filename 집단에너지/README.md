## 🧩 집단에너지사업이란?

<div style="background:#e8f5e9;border-radius:8px;padding:14px 18px;margin:0 0 16px;font-size:13px;line-height:1.8;">
<strong>집단에너지사업</strong>이란 하나의 발전소에서 <strong>전기와 스팀(열)을 동시에 생산</strong>하여 인근 산업단지 또는 지역에 공급하는 에너지 사업입니다.<br>
일반 발전소는 전기만 생산하고 열(약 60~70%)은 냉각탑으로 낭비하지만, 열병합발전(CHP)은 그 폐열을 활용해 스팀으로 공급합니다.<br>
→ 종합효율: 일반 발전 35~45% vs 열병합 80~90%
</div>

**집단에너지사업의 2가지 종류**

| 종류 | 설명 | 대표 사례 |
|------|------|---------|
| **지역냉난방사업** | 주택·상가 대상 난방열 또는 열+전기 공급 | 한국지역난방공사 |
| **산업단지 집단에너지** | 산업단지 입주업체에 공정용 열+전기 공급 | 한주, SKMU |

> SK가스가 추진하는 것은 **산업단지 집단에너지사업** (울산미포·온산 국가산업단지 중심)

**열병합발전소 방식 비교**

| 항목 | 증기터빈(ST) | 가스터빈(GT/복합) |
|------|-------------|-----------------|
| 연료 | 다양(석탄·LNG·바이오) | LNG·LPG 중심 |
| 종합효율 | 70~85% | **85~92%** |
| 전기효율 | 30~40% | 55~62%(복합) |
| 열:전기 비율 | 4:1~6:1 (열 主) | 1:1~2:1 (전기 多) |
| 기동시간 | 느림(수 시간) | **빠름(30분~2시간)** |

> UGPS(울산 GPS)는 가스터빈 방식 — 전기 생산 多, 빠른 부하 대응

## 🏛️ 구역전기사업이란?

<div style="background:#e3f2fd;border-radius:8px;padding:14px 18px;margin:0 0 16px;font-size:13px;line-height:1.8;">
기본적으로 발전·판매는 분리되어 있어 발전사업자가 직접 소비자에게 전기를 팔 수 없습니다.<br>
<strong>구역전기사업</strong>은 예외적으로 발전+판매를 동시에 허가받아, 한전을 거치지 않고 <strong>특정 구역 내 소비자에게 직접 전기를 공급</strong>하는 사업입니다.
</div>

**구역전기사업 2가지 유형**

| 유형 | 설명 | 규모 제한 |
|------|------|---------|
| 협의 구역전기 | 허가 구역 내 전기 직접 생산·판매 | **35MW 이하** |
| **의제 구역전기** | 집단에너지사업자가 추가로 받는 전기 직판 허가 | **500MW 이하** |

> **SKMU·한주**가 의제 구역전기 사업자의 대표 사례 — 산업단지 내 공장에 전기 직판

## 🔑 Hybrid 모델 핵심 메커니즘

<div style="display:flex;flex-direction:column;gap:12px;margin:0 0 20px;">

  <div style="background:#e8f5e9;border-left:4px solid #4caf50;border-radius:0 8px 8px 0;padding:12px 16px;">
    <div style="font-weight:700;color:#2e7d32;font-size:13px;margin-bottom:4px;">① 스팀 수요처 확보 문제 해결</div>
    <div style="font-size:12px;color:#333;line-height:1.7;">
      수요처가 <strong>스팀터빈 자가발전소</strong>를 설치 → 전기수요를 스팀수요로 전환.<br>
      전기가 필요한 곳은 어디든 잠재 수요처가 됨. 당사는 <strong>AIDC를 스팀 수요처로 개발</strong> 예정.
    </div>
  </div>

  <div style="background:#e3f2fd;border-left:4px solid #2196f3;border-radius:0 8px 8px 0;padding:12px 16px;">
    <div style="font-weight:700;color:#1565c0;font-size:13px;margin-bottom:4px;">② 500MW 용량 제한 해결</div>

## ⚠️ 주요 리스크

| 리스크 | 내용 |
|--------|------|
| ① 인허가 복잡 | 집단에너지 인허가 절차 복잡 (Step 1~8, KEA 검토·기후에너지환경부 허가) |
| ② 대형 스팀 수요처 확보 | Hybrid 모델의 핵심 — 충분한 스팀 수요처 없으면 사업 성립 어려움 |
| ④ LCOE 경쟁력 | 경쟁력 있는 LCOE(한전요금 대비) 확보가 어려울 경우 마진폭이 작을 수 있음 |

## 🚧 도전요소

① **정부기조** — LNG 중심사업에서 탈탄소 전환 압력. 탈석탄 기조와의 정합성 확보 필요
② **SKMU 연계** — 집단에너지 공급구역 내 기존 사업자(SKMU) 협력 구조 설계 필요
③ **초기 CAPEX** — 대규모 발전설비 투자 + 수요처 스팀터빈 자가발전 설치 지원
