## 💡 사업 개요

<div style="background:#e3f2fd;border-radius:8px;padding:14px 18px;margin:0 0 16px;font-size:13px;line-height:1.8;">
<strong>롯데SK에너루트</strong>는 수소를 연료로 전기를 생산하는 수소연료전지 발전회사입니다.<br>
SK가스와 롯데(롯데이니오스화학 LIC, 롯데정밀화학 LFC)가 합작(JV)해 설립했으며, 울산에 발전소를 운영 중입니다.<br>
수소발전은 발전단가가 높아(<strong>kWh당 400~600원</strong>) 보조금 없이는 시장경쟁 불가 → <strong>RPS·CHPS 보조금 구조</strong>가 사업의 뼈대입니다.
</div>

**수소발전 단가 비교**

| 발전 방식 | kWh당 단가 | 비고 |
|---------|-----------|------|
| 석탄 | ~80원 | |
| LNG | ~100~120원 | |
| 수소(부생/블루) | ~400~600원 | 보조금 없이는 시장 진입 불가 |
| 수소(그린, 수전해) | ~600~700원 | |

## 🔗 부생수소 공급망 구조

<div style="background:#f5f5f5;border-radius:8px;padding:14px 18px;font-size:12px;line-height:1.9;margin:0 0 16px;">
에너루트는 울산에서 <strong>청정수소가 아닌 부생수소</strong>를 연료로 사용합니다.<br>
공급원: <strong>롯데이니오스화학(LIC) · SK어드밴스드(SKA) · 롯데정밀화학(LFC)</strong> 3곳<br><br>
<strong>[5/2 셧다운 사례]</strong><br>
한주(구역전기사업자) Trip → LIC 전원 차단 → 부생수소 생산 중단 → 에너루트 전체 S/D<br>
→ 설비 자체 문제가 아닌 외부 도미노 — 3일간 순차 재가동, 매출 손실 약 3.6억원 (단기)
</div>

## 📌 ORC 프로젝트 (부가 사업)

<div style="background:#e8eaf6;border-radius:8px;padding:12px 16px;font-size:12px;color:#333;line-height:1.7;margin:0 0 16px;">
연료전지 운전 시 부산물로 발생하는 100°C 폐열을 활용해 추가 전기를 생산하는 <strong>ORC(Organic Rankine Cycle)</strong> 프로젝트.<br>
효율 10% 미만·CAPEX 높음 → 경제성 낮지만, REC 추가 확보 및 정부 폐열 활용 정책과 부합.<br>
울산에서 EPC 협상 타결, 연내 준공 목표.
</div>
