💡 SK가스가 서남권에 진입할 수 있는 3가지 경로

Path A: 발전소 지분 참여

정부 확정 3GW LNG 발전소(동서·남부·서부발전)에 지분 또는 LNG 공급자 지위로 참여. 인프라는 KOGAS·포스코·묘도 활용. SK가스 = LNG 도입 트레이더 역할.

강점: 자본 부담 낮음
약점: 서브 롤 (KOGAS 대비 경쟁)

Path B: 광주 인근 신규 열병합

광주 군공항 팹 인근에 SK 컨소시엄 열병합발전(1GW급) 신설. 팹 열·스팀 공급 = SK이노 용인 모델의 광주 확장.

강점: 앵커 수요 확실
약점: SK이노 E&S 선점 우려 → 사전 협의 필수

Path C: 서남권 AI DC 앵커화

SKT가 계획한 서남권 1GW AI DC를 앵커로, LNG 냉열 활용 발전소 신설. 응에안 모델의 국내 1호로 포지셔닝.

강점: 차별화 극대화
약점: 신규성·인허가 리스크 高

추천 우선순위: Path A (즉시) → Path B (사전 조율 후) → Path C (파일럿 검토). Path C는 응에안 검증 후 국내 이식 타이밍에 맞춰야 함.

💬 SK가스의 3가지 제안 (Talking Points)

제안 ① 울산 제2 복합발전 앵커 계약

UGPS(1.2GW) 옆 900MW 확장부지에 제2 복합발전 신설. SKT AI DC의 앵커 PPA 확보 시 SK가스 착공. UGPS와 공유 인프라 활용으로 CapEx 최적화, 전력 안정성 UGPS와 이중화.
Value: 앵커 수요 확보 · 앞선 900MW 부지 활용률 극대화

제안 ② KET #5 탱크 앵커 = SK-AWS AI DC

KET 5호 탱크(현재 앵커 미확보)의 앵커 테넌트를 SK-AWS 울산 AI DC로 지정. SK가스가 냉열 회수 설비 EPC/O&M, SKT/AWS는 냉각 시스템 인입. PUE 개선 시 DC 운영비 대폭 절감 + SK가스 KET#5 자산 활용률 상승.
Value: SK그룹 시너지 최대 · 응에안 국내 1호 이식

제안 ③ 서남권 파일럿: LNG 발전 + AI DC 결합

SKT가 계획한 서남권 1GW AI DC에 대해, SK가스가 인근 LNG 발전소 개발 파트너로 참여. 정부 확정 3GW(발전공기업 3社) 외 SK 자체 컨소시엄 트랙으로 병행 검토. 광주 팹까지 열·전력·냉 통합 공급.
Value: 응에안 국내 확장 · 서남권 진입 교두보

❓ 예상 질문 & 준비 답변
  • Q: SK이노 E&S와 어떻게 역할 나누실 건가요?
    → 용인=SK이노 E&S 이미 선점(1.05GW 열병합), 울산=SK가스 자산 우위(KET+UGPS+900MW), 서남권=계열사 합동 논의 제안 (§4 참조)
  • Q: 앵커 PPA 가격은 어느 수준을 생각하시나요?
    → 정부 발표 3GW LNG 발전소 SMP 대비 8~12% 프리미엄 (앵커 수요·안정성 대가). 세부는 조달비/발전효율 검토 필요
  • Q: 900MW 확장 착공 시점은?
    → 앵커 계약 확정 후 6~9개월 내 착공 가능. UGPS 인프라 공유로 준공 24~30개월 목표
  • Q: 냉열 활용이 실제로 얼마나 효과 있나요?
    → 응에안 프로젝트 상세 P/L 공유 후 정확한 수치 제시. 국내 KET 인접 여건 유리하다는 정성적 판단 우선

🎯 제안하는 역할 분담 원칙 (3가지)

원칙 1. Home Ground First

기존 자산·인프라 보유 지역은 해당 계열사가 리딩. SK가스 = 울산·평택 리딩 / SK이노 E&S = 용인 리딩. 계열사 영역 침범 금지 원칙으로 내부 경쟁 방지.

원칙 2. 신규 지역은 합동 컨소시엄

서남권(광주 군공항 인근) 등 신규 지역은 SK가스·SK이노 E&S·SKT·SK에코플랜트 합동 컨소시엄 구성. 정부·발전공기업 대응에서 SK그룹 단일 창구로 협상력 극대화. 지분은 사업 성격에 따라 리딩사 결정: 열병합=SK이노(용인 노하우), LNG공급=SK가스, DC=SKT, EPC=SK에코플랜트.

원칙 3. 기술 교차 학습

SK이노 E&S의 응에안 LNG+DC 결합 상세설계 노하우 → SK가스 국내 이식용 자원으로 공유. SK가스의 LPG-LNG 듀얼 연료 UGPS 운영 노하우 → SK이노 E&S 해외 프로젝트 확장 시 지원.
